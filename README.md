# Exercícios Básicos - HTML, CSS e JS

Repositório de exercícios práticos para praticar HTML, CSS e JavaScript.



##  Objetivo

### Praticar conceitos básicos de:

- HTML: tags, semântica, formulários, estrutura e barra de progresso
- CSS: bordas, botoes, fontes, sombras, cores e flex 
- JS: DOM, promisses, funções, fetch e async await

##  Como rodar

1. Clone o repositório
2. Abra o arquivo `.html` desejado no navegador
3. Ou use a extensão **Live Server** no VS Code



## Tecnologias

- HTML5
- CSS3
- JavaScript
