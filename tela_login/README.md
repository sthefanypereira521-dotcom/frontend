# Tela de Login

Projeto simples de uma tela de login, feito com HTML e CSS puro.

## Objetivo

Praticar os fundamentos de HTML e CSS, como estruturação de formulários, estilização e responsividade básica.

## Tecnologias

- HTML5
- CSS3


## Funcionalidades

- Campos de e-mail e senha
- Botão de login
- Layout estilizado
